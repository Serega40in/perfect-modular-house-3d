# Модульград — игровые арты

Сюда складываем изображения, которые используются игрой на GitHub Pages.

## Структура

- `houses/` — изображения домов, фасадов, модульных вариантов.
- `environment/` — деревья, кусты, трава, дорожки, заборы, фон и элементы участка.
- `construction/` — кран, строительные этапы, материалы и строительная техника.
- `ui/` — значки, портреты, декоративные элементы интерфейса.

## Как добавлять изображения

1. Используйте понятные имена латиницей: `house-scandi-01.png`, `tree-pine-01.png`.
2. Для прозрачных объектов предпочтителен PNG с прозрачным фоном; для фонов и больших иллюстраций подойдёт WebP или JPEG.
3. Не заменяйте существующие файлы новым изображением, пока оно не проверено в игре.
4. После загрузки пришлите список имён файлов или сами изображения в чат — мы подключим их к сцене и проверим отображение.

## Важно

Текущая 3D-сцена строится из процедурной геометрии Three.js. Обычная картинка дома не становится автоматически полноценной 3D-моделью: её можно использовать как иллюстрацию/текстуру, а для объёмной модели понадобится GLB/GLTF либо сборка из геометрии. Для начала лучше использовать арты как карточки проектов, фоны, текстуры и декали.

Не добавляйте секретные ключи, пароли или личные данные в репозиторий.
