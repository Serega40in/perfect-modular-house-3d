# Модульград by ЛенКаркасМодуль — этап 1

Браузерный MVP: изометрическая 3D-сцена, один участок, три каталожных дома, анимация установки краном, прогресс в IndexedDB (с резервным сохранением в localStorage).

## Запуск

Откройте `modulgrad/index.html` в современном браузере. Для 3D используется Three.js с CDN, поэтому требуется подключение к интернету.

## Публикация

Путь игры: `/modulgrad/` в GitHub Pages этого репозитория. Если Pages ещё не включён, откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/(root)`.

## Этапы

1. Вертикальный срез — текущая версия.
2. Конструктор: сетка модулей, планировки и полный каталог.
3. Производство: цех, бригады, склад и календарь.
4. Посёлок и жители.
5. Прокачка, заказы и интеграция с сайтом компании.
6. PWA и Android.

Цены в MVP перенесены из приложенного каталога проекта; перед публичным коммерческим использованием их нужно сверить с актуальным каталогом компании. Цена с отделкой обозначена как ориентировочная.
