# Модульград by ЛенКаркасМодуль — этап 2

Браузерная строительная игра на Three.js. Запуск: откройте `index.html` через GitHub Pages. Для загрузки Three.js нужен интернет.

## Уже реализовано

- Изометрическая 3D-сцена участка, окружение и кран с анимацией установки.
- Каталог типовых проектов и карточки площади, каркаса, цены контура и цены под ключ.
- Конструктор планировки 10×10: клетки по 1 м², инструменты площадь / дверь / окно / ластик.
- Предпросмотр пользовательской планировки в 3D и отдельный режим вида сверху.
- Сохранение пользовательских проектов, строительство собственного дома, демонтаж построенных домов.
- Автосохранение в IndexedDB с резервным вариантом localStorage.
- Экспорт и импорт игрового сохранения в JSON.
- Адаптивный интерфейс для компьютера и телефона.

## Важно про расчёты

Цены пользовательского проекта рассчитаны по простой ориентировочной ставке за квадратный метр и не являются коммерческой сметой. Типовые цены и сроки нужно сверить с актуальным каталогом компании до коммерческого использования. Механика игры не оформляет заказы и не отправляет данные на сервер: прогресс хранится в браузере.

## Запуск локально

Для ES-модулей и Three.js откройте страницу через локальный HTTP-сервер или GitHub Pages, а не через `file://`. Например, в папке проекта:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000/modulgrad/`.
